# Try the built-in sample

Start with **View Patch: Show Environment** or look above the file list in **Patch Reviews**.
The view shows the loaded extension version and whether it is running on your local computer, a remote host, or
in a browser.
No diagnostics are copied.

**View Patch: Open Sample Patch** opens a small two-file demo as a partial-context review.
It needs no repository and changes no repository files.
The sample shows only lines supplied by the patch, not complete files.
Try opening a file and marking it reviewed before bringing your own patch.
The unsaved sample is not added to **Reopen Recent Patch...**.

For troubleshooting, **Show View Patch Output** in the view's **...** menu opens the correct log channel.
**Report a Problem...** previews redacted diagnostics before you decide whether to share them.
