# Try the built-in sample

**View Patch: Open Sample Patch** opens a small two-file demo as an explicitly partial review —
no repository, no setup, nothing written anywhere.

Use it to see the Changes view, the Patch Reviews panel, and the read-only documents before
bringing your own patches.

If you ever need to report a problem, **View Patch: Copy Diagnostics** puts your version,
editor, platform, and Git details on the clipboard.
